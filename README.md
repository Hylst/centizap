# Centizap

Arcade shoot-em-up néon inspiré de Centipede. 5 thèmes visuels, power-ups, boss, musique procédurale.

## Jouer

https://games.hylst.fr/centizap/

## Commandes

| Touche          | Action              |
|-----------------|---------------------|
| ZQSD / Flèches  | Déplacement         |
| Espace / J      | Tirer               |
| P               | Pause               |
| R               | Relancer la partie  |
| F               | Plein écran         |
| M               | Muet                |

## Contrôles tactiles

Boutons à l'écran sur mobile/tablette.

## Développement

```bash
npm install
npm run dev     # Serveur de développement
npm run build   # Build de production
```
